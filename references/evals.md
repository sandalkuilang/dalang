# Evals: is the skill getting better?

Only when changing the skill. Run the golden briefs in autonomous mode (one fresh session each, invoked as a user would), then `node scripts/score_run.mjs video/<slug>` per project and compare with the previous scorecards. A score lowered without a reason is a regression.

## Golden briefs

Fresh topics each time (never a test topic again), same shape.

| # | Brief (user's words, in the user's language) | Stresses |
|---|---|---|

## What to compare

From `score_run.mjs`: `still_pct` (≤ 10), `lufs` (≈ −14 ± 1), `true_peak` (≤ −1), `qc_problems` (0), `timing_problems` (0), `est_words` (0), `assets_ok` (true), `gates_approved` (4), `review_p0` (0 open), `logged_minutes`, `logged_problems`, `quiz_score` / `quiz_pct` (correct = 1, partly = 0.5).

By hand beside the scorecard: Set and Reality (`visual-direction.md` §11), the people test, whether the voice sounds human. `POST.md`: its part 4 formula reproduces the film's number (with a `numbers.json`), ≤ ~1,800 characters, no credit line the user did not choose. Also tool calls and tokens per step, and any reference read whole when a section was enough.

**Scene code stays out of the main context:** the main session's transcript holds no `Write` or `Edit` to the film's `src/` or `assets/*.js` (any tool given a path, `Read` aside, counts); the Step 5 style frames (`style-frames/src/`) are the main agent's own. A path is the film's by device and inode, not spelling (a parent folder named `src` never flags; a symlinked folder still matches). Clean needs evidence: exit 0 with nothing printed only when the transcripts hold a builder's scene-code write; otherwise exit 2. Pass every session of the run (a resume starts a new JSONL) and the subagent files (`~/.claude/projects/<slug>/<session>.jsonl`, `<session>/subagents/*.jsonl`):

### Style frames are built from their reference

Every transcript that writes under `style-frames/src/` reads a `refs-board-*.jpg` before its first write, and the main session starts no style-frame builder `Agent` before the board-making call has returned done (a background call counts once its notification, `<status>completed</status>` and a Bash trailer `completed (exit code 0)`, comes before the builder). A call counts only once its result came back without error; a builder `Agent` counts when it starts. Main session first, then its subagent files. Nothing printed = clean, exit 1 = flagged, exit 2 = unknown, not clean (no style-frame write, a board command not yet done when the builder started, or a missing, empty or partial transcript: rerun):
