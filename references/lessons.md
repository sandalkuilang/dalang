# Lessons from real runs

Each line is a failure that already happened, tagged with the steps it belongs to (`[5]`, `[5,6]`); `state.mjs next` names a step's lines; a line without a tag fails the gate. Never read this file whole: when something goes wrong, `grep -n -i '<word>'` it. The fixes are already built into `SKILL.md`; this file says why.

## Script and facts
- [3] **Comparing numbers measured by different methods** and turning a tiny gap into a "narrow win" twist. A small gap with different methods is a tie.
- [1] **The format was never asked**, so the user wanted a vertical short but the brief stayed 16:9. Platform always goes through AskUserQuestion.
- [1] **The script was rewritten five times** because the brief (duration, language) was settled late. Ask everything in Step 1, before the first draft.

## Voice and timing
- [4] **A warning that says "listen" is not actionable for an agent.** A low-alignment warning pointed at a spot to listen to; the agent moved on and the user heard the noise there. A full re-take costs 15–25 min, so three bad sentences were re-spoken and hand-spliced with ad-hoc crossfades. `--retake auto|<n,…>|changed` re-speaks and splices only those sentences; every warning names a command, never "listen" or "check by ear".
- [4] **A heavy chunk timed out and the abandoned job kept the device,** so an immediate retry failed again; the script printed `FAILED` and the agent restarted the app by itself. Chunks stay within the engine's limit (120 characters for VoxCPM2), and a `503` waits, retries once, then is a `WARN … rerun` with exit 3: BUSY means wait, never restart.
- [4] **Per-sentence timing ≠ per-word timing.** A per-sentence transcript is accurate only to ~1/6 s. Use `words.json`.
- [4] **One number-heavy section is not a representative pace sample** (2.09 vs 2.30 words/s for the full script, same voice). After the full generation, re-check the real duration.
- [4] **Accent tags changed the pace** (2.30 → 2.57 words/s; 134 s against a 150 s target). Calibrate with the tags you will use; fix small misses with `--speed`.
- [0,4] **Time lost on account issues:** 401 (key permission) and 400 `paid_plan_required` surfaced only after a clone sample was prepared. `preflight.mjs` shows the tier first.
- [0] **VoiceStudio "loaded forever"** on the first generation: the backend downloaded the AudioSeal watermark inline, stopped answering `/health`, and the app restarted it every ~60 s. Pre-download outside the backend (`voice.md`).
- [0] **A wait loop trusted `installed: true`** while a model was still downloading; the first request hung the single Apple Silicon worker for 30 minutes. Wait for `incomplete: false`.
- [4] **The transcription endpoint ignored the installed MLX turbo model** and demanded a 3 GB one. Activate faster-whisper turbo through the balanced tier (`voice.md`).
- [4] **"Use the voice from this chat voice note" stalled Step 4** for ~10 tool calls: no clone path was written down. Now `voice.md` "Clone".
- [4] **A clone profile made in the app (60 s clip, no transcript) answered a raw 500** and cost ~6 calls to diagnose. `tts_timestamps.mjs` now names the fix (re-save 3–10 s with `--ref-text`) and `--save-profile` refuses clips over 20 s.
- [1,4] **Three voices were auditioned before anyone asked** — the user wanted their own saved profile. Ask which saved profile to try first (`script-voice.md` §4).
- [1] **A saved clone was used for a public channel without asking:** the user first saw it in the Gate 1 summary and rejected it. The Brief asks the voice by audience (`brief.md` Call 3). Saving the approved designed audition then failed on its length; `--save-profile` now cuts it at a word end from its `.words.json`.
- [4] **A saved voice came out as the default voice, with no error:** the profile name went to VoiceStudio as-is, and it matches profiles by `voice_id` only, so an unknown name falls back to the default (same seed → identical audio). `tts_timestamps.mjs` now resolves a name to its id and stops on an unknown voice. When a user says "that is not my voice", compare against `--voice <id>` first.
- [4] **A clone spoke slower and paused longer than its sample suggested,** with ~1 s pauses holding room tone that `silenceremove` cannot see, and dropped a word in a long take (its "estimated" warnings were real gaps). Measure the pace on the clone itself, rephrase a dropped line, cap pauses by cutting on `words.json` gaps, then retime with `--from-audio` (without `--own-recording`: the cut take keeps its model's licence).

## Visuals
- [5] **The animation looked cheap and generated:** "the brief is settled, don't re-ask" made `/hyperframes` skip its SPEC/LOOK step; the hero (a vehicle) was drawn from SVG primitives; banned defaults appeared (cream ground, pill chips, side-by-side panels on 9:16, the same pop-in everywhere, a small hero in an empty frame); nine scenes were built before anyone saw one finished frame. Fixed by `SPEC.md`, the realism ladder, style frames, and blocking/polish passes.
- [5,6] **Half the film was still** because only mouths moved. A good reference film is ~5 % still.
- [5] **A vector animal passed every check** because the illustrated look allowed rung 6 and the Realism test was "N/A". Realism is now an explicit Step 1 choice (hyperreal or stylized): a hyperreal subject is never drawn, a stylized one is drawn on purpose, and the Realism and Reality tests apply to both — a stylized machine still has every part where the real one has it.
- [1,5] **A "cartoon" pass in saturated candy pastels on a coloured backdrop was rejected as cheap**; the user preferred the studio-diorama look of the best three.js demos: a designed object on a seamless light sweep, a calm palette with few accents, soft even light, a three-quarter view. Stylized means designed, not loud.
- [1,5] **A palette went three rounds before it was liked.** A light hero on a light ground of the same value merged (uncomfortable to watch); a muted mid-grey ground read sleepy; a saturated ground read garish. What worked was measured from a reference the user liked: a light, warm set and a hero that reads through its dark parts and contact shadow (look C, rubric Figure-ground).
- [5,6] **People looked stiff** — poses and movement read as puppets, far from real. A person in a hyperreal film moves only as real footage (a generated clip only on paid request), never as an animated cutout or rig (`visual-direction.md` §1 "People").
- [1] **Calm cinematic built to its numbers was 24 % still.** Calm needs real continuous motion too (`visual-direction.md` §3 "Minimum motion").
- [1] **Step 1 preview promised banned defaults** (navy gradient + starfield) and the user picked it. Previews now follow the banned list.
- [6] **Half a character vanished:** SVG parts inside `<template>` parse as HTML (self-closing `<path/>` is ignored, shapes nest and don't draw). Keep reusable SVG in `<defs>` and clone it with `<use>` or JS.
- [6] **A crossfade between two shots of the same hero showed two of it** for 0.3 s. Same hero across a seam → match cut (same screen position and size), never a crossfade.
- [6] **`mix-blend-mode` on an SVG `<rect>` rendered opaque** and hid the hero. Use a CSS `filter` on the shot wrapper.
- [6] **Text rendered in a fallback font:** the face was set with the CSS `font:` shorthand, and the render's font subsetter reads only `font-family` declarations, so the bundled face was never embedded. Set `font-family` on its own (`look-build.md` scaffold facts).
- [6] **An animation moved an object in another scene:** two scenes reused one scene-local `id` (`title`, `card`), and the lookup found the first scene's element. Prefix every `id` with its scene (`look-build.md` scaffold facts).
- [6] **A template beside `index.html` failed `check`** (`multiple_root_compositions`), and `media-treatment` patched the file `fill_times` regenerates. Template lives at `src/index.tpl.html` (SKILL.md "Project files").
- [5] **A licensed Commons "documentary" clip was a cartoon** (37 MB downloaded for nothing). Look at posters on a contact sheet before downloading (`visual-direction.md` §1 "Sourcing").
- [6] **Missing GSAP include and a timed `<video>` inside a timed wrapper** each cost a check round (`look-build.md` §6.4).
- [5] **Non-English catalog queries** return zero results.
- [5] **A generated action happened in the wrong place three times** (the right action on the wrong part of the object) — the stills passed a Reality check that looked at materials, not at where the action happens. The check now names the location (`visual-direction.md` §1).
- [5] **A generated machine had a major part outside its body**, then on the wrong component; four generated stills, no real photo searched (only Commons video), the reference "checked" from memory. Machines start at rung 1–2 and the Reality check compares against a downloaded photo (`visual-direction.md` §1 "Machines").
- [5,6] **`remove-background` holed a product label** (it is a person-segmentation model) and a green screen keyed a dark product; ~10 calls went into a hand-written key. Products are generated on a white light box and cut with `scripts/key_white.py`.
- [6] **A kinematic body that jumped flung what it touched:** a tool parked away from the set and then set straight into place got a huge speed for one step. A kinematic body moves along a smooth path (ease in and out of its place), never a jump.
- [6] **Thin pieces tunnelled through a thin triangle-mesh wall or floor** (a leaf through a vessel's shell) even with CCD. Back a thin static shell with solid colliders (a cylinder under a floor, a ring of cuboids outside a wall).
- [6] **Floating pieces read as sinking** when buoyancy used the liquid's own level: the surface stands on the liquid plus the volume everything in it displaces. Raise the level by the submerged volume (last step's) before computing each piece's buoyancy.

## Audio and reference
- [7,8] **The first render was ~8 dB too quiet.** Always run `loudness.mjs`; normalising the narration before the mix gets it right first time.
- [6] **Lint flagged 45 "duplicate audio tracks":** SFX `<audio>` without `data-duration` count as playing to the end of the film.
- [7] **`hyperframes preview` opened the user's own Chrome**: its `--open` defaults to true. Always `--no-open`, on every re-run with other flags too, and in the `dev` script `hyperframes init` writes to `package.json` (it has none); then the URL in Claude's isolated built-in browser (`qc.md` §7). HyperFrames' headless render Chrome is its own bundled copy and is fine.
- [5,7] **`snapshot` sends frames to Gemini** whenever `GEMINI_API_KEY` is set. Pass `--describe false`.
- [6] **No music source** left Step 6 undefined. Music is now a licensed free track (Openverse, CC0 first then CC BY, no key; `scripts/find_media.mjs --type music`, `look-build.md` §7); nothing fits → narration + SFX, and say so.
- [6] **`find_media.mjs --type music --licence cc0` was always empty.** Openverse's CC0 music (Freesound) carries no `category`, so a `category=music` filter dropped all of it, and "nothing matched" read as "there is no CC0 music". Music is now told from SFX by duration (`--min-duration`, default 20 s), and the order is CC0 first, then CC BY with a visible-credit note. A provider's `mp32` filetype is saved as `.mp3`. The drafted social caption never carries a credit line unless the user chose one.
- [2] **YouTube auto-captions had gaps**, including in the key sentence. Transcribe a reference again and read it to the end.
- [2] **The assistant studying a video cannot hear.** Sound effects read from images are guesses; mark them.
- [6] **`media-use resolve --type sfx` found no provider**; the free sources are the bundled `/media-use` library and Openverse CC0, both through `scripts/find_media.mjs --type sfx` (`look-build.md` §6.7).
- [5,6] **Throwaway search scripts, and a hand-built manifest.** Each film re-wrote an Openverse and a Commons search (fixed `sleep`s between queries, ~11 min for one music track), and listed the engine's ~25 copied files in `ASSETS.json` as "generated, MIT", which is false for vendored code. `scripts/find_media.mjs` searches and `--take`s with the row filled from the API (backing off on 429); `build.mjs` lists the engine's files itself in `assets/.engine.json`. Never write either by hand; a licence guessed from memory (a bundled SFX pack taken for CC0) is read from its own credits file instead.

## Working speed
- [0,1] **A 242k-token session**: one long conversation carried a voice-clone detour, five script drafts, and two copies of the skill. State lives in files — start one session per video and resume from `BRIEF.md` + `PRODUCTION.md`.
- [7] **A 30 fps draft render took 39 min** (the next took under 3): nobody stopped it. A render far slower than the last → stop and look for the cause.
- [7] **A 10 fps draft rendered in half the time** and gave the same stillness and loudness verdicts. QC renders run at 10 fps; the user reviews in `preview`.
- [8] **The final came out at 30 fps, not the brief's 24:** `hyperframes render` defaults to 30 fps and the Step 8 command passed no `--fps`; `qc.mjs --fps` caught it, after a full re-render. The brief's fps is always passed to every render (`qc.md` §8).
- [7] **Every QC round rebuilt its review sheets by hand:** still times computed from the shot list, ~70 frames snapshotted, then ~10 ad-hoc ffmpeg tile commands per run (snapshot names large sets `contact-sheet-1.jpg`, so the expected name missed). `strips.mjs` does it in one call (`qc.md` Step 7).
- [7] **An unattended run delivered known "looks wrong" P1s** (Reality, Clarity); the user's first ask was to fix them: another polish pass and another final render. With the user away those P1s (and Realism ones) now block the final.
- [8] **Generic build traps went into the user's private memory**, so the skill and its other users never learned them. The hand-off's `## Skill feedback` section carries them upstream (`qc.md` Step 8).
- [4] **Background TTS was polled** by reading its output file. Background jobs notify on exit; the scripts end with `DONE`.
- [4] **Whisper timed sentence starts early** (it counts the pause as part of the next word, up to 0.7 s). Forced alignment against the known script fixed it — beats on sentence starts land on the voice.
- [4] **VoxCPM2 timed out** (300 s compute limit) on its first call while OmniVoice and a benchmark held the memory; alone it worked at ~22× real time. Heavy model jobs run one at a time; VoxCPM2 gets ~120-character chunks.
- [5,6] **Two queued jobs waited on `pgrep -f <image generator>` for 25 min with nothing running**: each waiting shell's own command line matched. Chain heavy jobs in one background command, or wait on a PID (SKILL.md).
- [5] **The machine sat idle through a 58 min gate wait**, then remaining stills and music ran serially after it. Free local jobs that a "no" only discards run during the wait.
- [5] **The film read as a PowerPoint slideshow:** 14 drifting stills with text in 61 s (Punchy energy wants ≥ 34 shots), the key action a frozen photo, nothing shown of the mechanism the narration explained. `stillness.mjs` said 0.8 % still because the rule let a ≥ 30 px/s drift count as motion. Now the subject must act in every shot, camera-only plates are ≤ 15 %, every "why" gets a mechanism shot, and the reviewer runs an Action test (`visual-direction.md` §3, §8, §11).
- [5] **Every "camera move" was CSS on a still** (pushes and drifts on 14 stills): no tracking, no orbit, no slow motion, no B-roll — the film had no cinematography to speak of. Real moves come from footage, a 3D rig camera or (paid, on request) a generated clip, cut as A-roll and B-roll with one wow shot (`camera-motion.md` §10).
- [7] **Rework, not rendering, was the slow part** of a 3 h 43 min run: a 27 % stillness fail (static plates) cost a 7.5 min re-render; 5 of the reviewer's 7 P0s were asset defects found after the full build; `check` next to a model job took 9× longer. Now: drift, scene-prefixed ids and overlapping whips from the first draft (`look-build.md` §6.4), an asset pass before building (`review.md`), browser steps never beside a model job.
- [5,6,7] **`PRODUCTION.md` logged every step as `HH:MM–HH:MM` with start = end** (both written at the end), so `logged_minutes` was 0 and no ETA could be given; the user asked "how long?" three times. `state.mjs log` takes the start from the previous line.
- [5,6] **A stylized room read as a toy** with its furniture in place; adding dense small props (things on every surface, cables, real-leaf plants, a pinboard) and a few small life motions lifted it more than any lighting or material pass. Set dressing is now a recipe and a review test (`looks.md`, `visual-direction.md` §11).
- [6] **A desk chair swivelled around a corner of its base** on an endless sine: the kit model's origin was not its pivot, and nothing caused the motion. Motion now has a cause and real physics: kinematic pushes on friction curves, simulated contacts, real pivots (`camera-motion.md` §5).
- [6] **A physics bake that looked right was wrong in numbers:** a chair shoved 105 mm before frame 0 by its own seat collider, books overlapping 7.6 mm, every desk prop 4.4 mm inside the desk, a radio 28 mm in the air. Only the bake's report (penetration, pre-roll drift, placement audit) found them; now every bake prints it and the shot is fixed until it is clean (`camera-motion.md` §5).
- [5,6] **A cozy stylized room still read as boxy and CG** after the set dressing: faceted kit models, flat untextured colours, a blob cat, a lamp that glowed but lit nothing, a monitor picture floating in front of its bezel. Subdividing everything melted hard furniture into clay; subdividing only soft goods, procedural surfaces on every material, a cat built from its anatomy with combed shell fur, physical lamp cones and a screen fitted to the model fixed it (`looks.md`, true shapes and surfaces).
- [6] **The first fur looked like a hedgehog with tree rings:** strands on a 3D grid sliced by the skin into rings, standing straight out. Strands on the skin's uv, combed along the body, fixed both.
- [6] **Two black frames** came from a swept tube's closed tip: zero normals became NaN in the shader and bloom spread them over the frame.
- [6] **A fan's wind passed through a monitor** to move the curtain behind it, and the curtains hung through the desk top. The jet is now blocked by the objects in its way (tested once every prop is placed) and the curtains end above the desk.
- [6] **`settle` refused props placed a few cm high** (a ball dropped in a bin, cushions held above a seat) and left them floating; it now drops a prop any distance onto what is under it, as gravity would, and only reports a prop placed inside something.
- [6] **A whole set ran at the wrong scale:** the kit's unit was 1.95 m, so gravity at 9.81 units/s² made everything fall 1.4× too fast (the "miniature" look), a cat was 54 cm curled up and books twice their size. Measure metres per unit from known objects first; physics in real units, props at real size.
- [6] **Placement looked fine and was wrong in four ways the reports found:** a desk dropped 24 cm through the floor (one ray under its centre fell between its legs), a cushion hung on the edge of a sofa back (first contact, never a stability check), a plant's leaves inside the books beside it, a phone sunk into the desk top and then dropped through it. Lowest-points settling, loose props simulated, and every settle miss read with the report fixed them.
- [6] **A chair "drifted" 6 cm before frame 0** — measured at a kit origin on a corner, so a 2° turn read as centimetres; at the centre of mass it was real: one caster 7 mm from a rug's edge was shoved sideways by it. Drift is measured at the centre of mass; casters clearly on or off a rug.
- [6] **A rolling chair barely slowed:** the resistance acted on its base while the seat, on a joint, kept its momentum. Resistance goes on every body of a jointed thing.
- [6] **Per-film caption code lost contrast over the dark parts of a set, clipped labels pinned near the frame edge into the platform's rail, drew them below the size floor, and repeated a label in the caption:** each film rewrote the phrase split and the drawing. The engine's `type.js` owns them (`phrases`, `drawCaption`, `pinLabel`, `repeats`): ink from the ground under the box, labels clamped inside the safe area above the caption, a warning on a repeat.
- [6] **A released part came back to its held pose in two later shots:** the release was hand-written (an own integrator, one time function per phase, slow motion and the replay by hand). Mechanisms are engine parts (`mechanism.js`: stops, spring, latch), and slow motion and replays remap time on the one bake (`slow`, `replay`), so every shot reads the same motion.
- [6] **Hull building aborted (wasm `unreachable`)** on a cushion: thousands of crowded near-coplanar points, then NaN vertices from `sqrt` of a tiny negative at the edges. Points one per cell; clamp before `sqrt`.
- [7] **Reading a stale preview iframe** gave identical numbers after a change: the Studio keeps an old player iframe beside the new one. Read the newest (`_t=` in its URL) and record build errors on the host object.
- [6] **A physics bake ran again for every snapshot and every page load of a render** (~100 s each; one final render loaded the page twice, so half its 9 min was the same bake). `bakeCached` + `engine/three/bake.mjs` bake once; every snapshot, preview and render worker reads the file.
- [6,7] **Context grew to ~590k tokens in one run, never compacted:** 21 full-size snapshots and every verification log stayed in it, and each of 257 calls re-read it all. Verification loops run in a subagent that returns a text verdict; the user is told at Gates 3 and 4 that `/compact` is safe.
- [6] **Scene files were patched with inline scripts** (`python3 - <<EOF`, `sed -i`): about 50 patches, ~94 k characters of tool input, and two swallowed the code after an inline comment. Scene changes are `Edit` calls.
- [0] **Three quarters of the skill's docs were read into the main context** (whole-file reads of references, the lessons and the engine README), and every later call re-read them. `state.mjs next` prints each step's sections; nothing is read whole.
