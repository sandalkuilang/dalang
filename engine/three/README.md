# DALANG three.js engine

Generic 3D systems proven on real renders: real scale and placement, true surfaces, section views, made-thing parts
(fasteners, bearings, gears, belts, boards, wires), fields and light as subjects, granular fills, camera stations and
attention, and the frame finish; plus a small catalogue of ready pieces built on them. Nothing here knows a scene or a
topic: every input is a parameter in real units, every preset (a kit's material names, a palette) is passed in by the
set. Every motion is a pure function of t from its cause (a ratio, a law, a cue): no physics engine, no bake, so any
frame renders on its own. The rules behind every number are in `references/looks.md` (true shapes and surfaces) and
`references/camera-motion.md` §5 (physical timing).

## Install into a video project

```bash
node <skill-dir>/engine/three/build.mjs <project>/assets
```

The build also writes `<project>/assets/.engine.json`: every file it copied, with its real origin and licence (the repo's MIT for the engine and examples; each vendored npm package, with version and licence, for the bundles). `scripts/check_assets.mjs` reads it, so these files are never listed in `ASSETS.json` by hand.

```bash
node <skill-dir>/engine/three/selfcheck.mjs <project>/assets
```

The build copies the modules and bundles `three-vendor.js` (three 0.186.1 and its add-ons, postprocessing, N8AO,
three-subdivide) from pinned versions; the first run installs them into
`vendor/node_modules`. The self-check fails loudly if a known trap is back (NaN in maps, zero normals, a tolerance that breaks at another scale, a cut cap coplanar with a face or a part the cut plane misses, a granular fill with grains on the removed side or stacked into one blob, a camera route that jumps (a hard cut), a ghost left on after its release, a dimension line or label outside the safe area). Import everything from
`assets/` so all modules share one `THREE`.

## What it covers, and how it grows

The engine holds behaviours (laws), never a list of objects. The systems: scale and placement, procedural surfaces,
parametric machine parts and transmissions, electricity, fields and light drawn by their law, granular fills, section
views, camera stations and attention, the finish. `examples/` holds ready pieces built on them, proof of how to use the
systems, never required. A moving part is posed from its cause at t: a gear by its driver's angle times the tooth
ratio, a fall by the place's gravity with an eased landing and a short contact squash, a latch released on its cue.

The engine is a toolbox, not the limit of what a film shows. Not here: physics simulation, cloth, fur, water, plants,
creatures, people. A film that needs a subject the engine lacks builds it from three.js the same way: the law that
drives it and its real numbers from a cited source; parameters in real units, nothing that knows the set; a scale
changed on purpose and shown when reality is too small, large, fast or slow (`camera-motion.md` §5, "Any subject
moves by its own law"); its trap added to `selfcheck.mjs`; proved in the render; then brought back here with a line
in this table.

## Modules

| Module | What it gives |
|---|---|
| `kit.js` | `makeKit(scene, { mpu, floor, wear, palette, kinds, grain, gravity })`: sets the scale and the place (`M` metres per unit; `G` the place's gravity, 9.81 m/s² by default, in units/s²; live for every module; every tolerance is in metres, so any scale works); `model(path, opts)` loads a `.glb`/`.obj`, its materials dressed by name (`palette` colours, `kinds` surfaces: presets `kits.furniture`, `palettes.americanJapandi`; unmapped materials stay as they came), soft goods subdivided; `box`, `cyl`, `tube` (cables kept off the floor), `mat`, `cloth`, `canvasTex`, `group`, `paint`; `rest(o)` + `settle()` drop every prop onto its first contact by its own lowest points and return what could not be placed (nothing below, or more than 3 cm inside something; up to 3 cm it lifts out); `model(path, { crease: false })` keeps a detailed model's own normals; `model(path, { palette, kinds, real })` gives a found (CC0) model its own look, merged over the kit's and never leaking into it, and its stated size `real = { h, w, d }` in metres, which `scaleAudit` checks (none: listed unchecked); Draco-compressed glTF loads (the wasm decoder is copied to `draco/` and listed in `.engine.json`); `screenOn(model, material, picture)` lays a display on the model's own screen face. |
| `surfaces.js` | `surface(material, kind, { world, wear, floor })`: procedural triplanar detail with no UVs — `fabric`, `pile`, `wood`, `bamboo`, `plaster` (wear 0..1), `micro`, `bark`, `stone`, `soil`, `grains` (packed grains, `{ size, long }`). |
| `parts.js` | Machine parts at their standard proportions, for a mechanism assembled instead of modelled (look K): `bolt({ size, length })` (ISO 4017, threads at the ISO 261 pitch), `nut` (ISO 4032), `washer` (ISO 7089), `bearing({ code })` (608, 6000, 6200-6204: rings with their raceway grooves, balls in them; `spin(a)` rolls the balls at the cage speed), `spring({ wire, mean, coils, free })` (closed ends; `setLength(L)` compresses the active coils evenly between solid and free, `rate` and `force(L)` from G d^4 / 8 D^3 n), `shaft`, `knob`, `housing({ w, h, d, r })` and `xray(object)` (the look K shell: its own transparent material, drawn after the parts, silhouette edges, left alone by `attend`). Metres in a group at 1/M, the real size declared, `mat` for the accent; a size outside the tables is refused. Gears, belts and chains are `transmission.js`, boards and cables `electronics.js`. |
| `transmission.js` | The geometry of what the couplings tie together, in metres (scale a mesh by 1/M). `involute({ module, teeth, pressure, backlash })`: a spur gear outline at a real module (2 mm, not 2) and tooth count, with `rp rb ra rf`; `meshing(g1, g2)` gives the centre distance m(z1+z2)/2 and the phase at which two mesh, and refuses an interfering pair (12 teeth at 20° against 36: use 25°) or a contact ratio under 1; `gearGeometry(g, { width, bore })` the extruded solid. `pitchRadius(teeth, pitch)`; `loopPath(wheels)`: the closed belt or chain path over `[{ x, y, r, inside }]` (counter-clockwise, `at(s)` gives the point and travel direction); `openLength`, `centreFor({ links, pitch, r1, r2 })` (the centre for a whole number of links); `linkPoses(path, { pitch, phase })`; `angleOf` and `phaseOf(q, q0, axis, teeth, pitch)`: where the links are, from the driver wheel's pose alone (any frame order, render workers included). |
| `type.js` | Captions and labels on the film's 2D canvas, no imports (browser and Node). `readTime(text)`: the least time a label needs on screen (0.5 s + 0.3 s per word + 0.15 s per CJK character, at least 1 s). `phrases(narrationTxt, words)` → caption phrases (`craft-rules.md` §6: a narration line end, sentence ends, `,` `:` after 3 words, a run over 7 words at its longest speech pause in `words.json` (≥ 0.3 s) else balanced, CJK by character ≤ 16, held through the pause that follows; `scripts/captions.mjs` writes `audio/captions.js`); `drawCaption(ctx, t, caps, { format, accent, pill })` in the format's caption zone (the target band of `craft-rules.md` §6; Reels and TikTok: block top about 73 %, bottom 82 %), ink from the luminance under its own box (decided every frame, halo in the other ink), the spoken word boxed in `accent` from its start, never drawn outside the zone (a phrase that does not fit in two lines at 54 px shrinks: `shrunk`); `pinLabel(ctx, { at, camera, text }, { format, side })` a label with leader that flips and clamps inside the label zone above the caption, ≥ 36 px, wrapped at its spaces when wider than the zone, `null` for a point behind the camera or off the frame; `{ pill: "#ffd400" }` makes it look J's label (dark text on a pill of that colour, a dark leader ending in a ringed dot on the part, no halo), `{ top }` keeps it under a y in px (the text band's `box.y1`); `textBand(ctx, { kicker, headline, tag }, { format, size, scrim })` look J's text band at the top of the label zone: a tracked monospace-caps kicker (≥ 36 px), a bold headline that states the claim or the number (64-96 px, two lines, `shrunk: true` when it had to go smaller), an optional dark status tag, on a light scrim, all inside the zone; returns `{ box, kicker, headline: { box, lines, size, shrunk }, tag }`, a headline is required; `recordBox(kind, text, box, size)` hands a box drawn by another module (`dimension`) to `layoutFrame`; `repeats(caps, labels)` warns when a caption repeats a visible label; `rangeBar(ctx, { value, max, ticks: [{ at, label }], label }, { format, x, y, w, size, accent, highlight })` a range card (`visual-direction.md` §13 "Formula on the set"): the bar fills to `value / max` (clamped), a tick at each option's capacity with its label under it, the first tick at or above the value (or `highlight`) in `accent`; kept inside the label zone, ≥ 36 px; returns `{ x, y, w, h, fill, fits, ticks, size, ink }` (`fits` -1: no option fits); `safeArea`, `luminance`, `inkFor`. Call after the finisher has drawn the frame (it reads the ground). `layoutFrame(ctx, t, { format, hero })`, called last in the frame function, hands out the boxes drawn since its last call as `{ t, W, H, format, hero?, boxes: [{ kind, text, x0, y0, x1, y1, size }] }` (`kind` caption / label / card, px at the canvas size; `hero` from camera.js `heroBox`, left out when not given, `null` when the hero is off the frame); it sets `globalThis.__dalangLayout` and posts the record to `strips.mjs`'s receiver on 127.0.0.1:47614 while one answers (the first failed post stops the posting for that page; `send` takes the JSON instead of the post), so `review/strips/index.md` carries the numbers for `scripts/layout_lint.mjs`. |
| `quantity.js` | Quantities shown in the world (`visual-direction.md` §13). `flowArrow({ from, to, value, scale, normal, color, head })`: a flat arrow from `from` to `to` (scene units) whose shaft is `value × scale` metres wide, so two arrows on one scale show their ratio (the film keeps one scale); it lies in the plane facing `normal` (+Z by default; parallel to the arrow throws), value and scale must be finite numbers > 0; `reveal(u)` draws the first `u` of its length at the same width; `anchor` is where its value label goes (`pinLabel({ at: arrow.anchor, ... })`); returns `{ group, mesh, anchor, value, width, length, reveal }`. `tileFill({ at, w, d, cell, color, gap, lift })`: a `w × d` m area on the floor from the corner `at`, in cells of `cell` m (the last row and column cut to fit), one InstancedMesh lifted 2 mm with a `polygonOffset`; `show(n)` shows the first n cells (row by row along +x, then +z), `area(n)` their m² (the card's value, so card and tiles agree), `edges.w` / `edges.d` anchors for the dimension tags. Neither adds itself to the scene; an arrow or tile fill is not a prop, so `scaleAudit` lists it `unchecked`. `dimension(ctx, a, b, { camera, text, dir, gap, off, over, size, top })`: a drafting-style dimension line drawn on the frame (extension lines, an arrowhead at each end, the value in monospace rotated with the line and never upside down; `a` and `b` are world points in scene units, `text` the value from the numbers model, `dir` the side it stands off to, made perpendicular to the edge); it stays inside the label zone: it stands off on the other side, then closer, and if neither fits it draws NOTHING and returns `{ drawn: false, why }` (a dimension never runs off the frame); `null` for a point behind the camera; the value's box is recorded for `layoutFrame`; `top` keeps it under the text band. |
| `circuit.js` | Electricity made visible, every `at(t)` a pure function of t from the numbers model's functions (amperes, volts, watts, joules), never keyframed. `wire(path, { kind, radius, color, normal })`: a `trace`, `wire` or `busbar` along ≥ 2 points (straight legs with round corners) or a `THREE.Curve`, typical radii 0.4 / 1.5 / 4 mm (override from the part); `length` in m, `pointAt(s)`, `frameAt(s)` (s in metres from the start). `flow(wire, { current, waveform, freq, speed, timeScale, fps, amplitude, duty, full, width, perAmp, color, samples, lift })`: pulses travelling at the stated visualisation `speed` (m/s, not drift velocity) in the waveform's shape: `ac` a sine wiggle (wavelength = speed / shown frequency), `dc` a straight line, `pwm` chopped blocks (`duty`), `3phase` three ribbons 120° apart; width = `width + perAmp × |I|`, brightness = `|I| / full` (the film's one scale: two flows share it), no current draws nothing. Mains frequency cannot be seen at 30 fps: `timeScale` slows it on purpose (shown = freq × timeScale) and a shown frequency above `fps / 4` is refused (`/alias/`), as is a wavelength under 6 samples; `label` is the on-screen line ("AC 50 Hz shown at 1/10 speed; pulses at 0.5 m/s for visualisation, not drift velocity"); `sample(t, n)` gives the maths (`{ s, y, on }`), `at(t)` → `{ current, halfWidth, brightness }`. `flowArrow` (`quantity.js`) shows a flow's magnitude, `flow` its behaviour in time: a film uses one of them for a quantity. `glow(mesh, { power \| temperature, area, emissivity, h, ambient, exposure })`: a hot part's emissive colour by black-body (`blackbody(T)` → `{ color, Y }`; nothing under the Draper point `DRAPER`, 798 K); `power(t)` W gives the STEADY-state temperature from convection plus radiation (a part with thermal mass lags: give `temperature(t)` K instead); the mesh's material is cloned, a shared one is never written. `lamp(light, { rated: { V, lm } \| curve: [[V, lm], …], voltage, type, cct })`: the light's candela (lm / 4π) follows the supply voltage by the type's cited curve (`LAMPS`: incandescent flux ∝ V^3.4, colour cooling with V^0.42, with its source) or a datasheet table; a type with no curve is refused; the light stays in the scene at intensity 0. `arc(kit, { from, to, t0, dur, energy, efficacy, timeScale, fps, seed, branches, sparks, sparkSpeed, sparkTemp, cool, ground })`: a seeded branching discharge; its PointLight (efficacy × energy / dur lumens) and channel exist only in `[t0, t0 + dur / timeScale)`; `energy` and `efficacy` have no default (from the model, with a source); an arc shown for under one frame is refused (`/frame/`: slow it with `timeScale` and say so); sparks fly by gravity from the middle (closed form, no drag) and show by black-body colour until they cool below 798 K; `events` is the event row (`arc-flash`). `at(t)` → `{ on, intensity, sparksLit }`. `failure(part, { kind, at, amount, vent, soot })`: a Mesh that fails at the model's event time `at` (s): the variant (`bulge` a domed, optionally vented capacitor top; `blown` a fuse wire in two pieces with a gap and a soot mark; `char` a burnt resistor or varistor; `melt` a sagging connector) is built once beside the part with its own geometry and material, `at(t)` shows the part before the event and the variant from it (pure of t, the part's own material never written); an unknown kind or a non-finite `at` is refused. Nothing here adds itself to the scene; `scaleAudit` lists these `unchecked`. |
| `instruments.js` | Live widgets on the film's 2D canvas (draw after the finisher, in the text band; the same functions draw a device screen into a `CanvasTexture`'s canvas). Each reads the model's number and needs `units` and a `label` (refused without); text is never under 36 px; a value that cannot be read shows `--` or a gap and is returned as null, never drawn as 0; each returns the numbers it drew. `scope(ctx, { signal, t, window, range, units, label, x, y, w, h, divisions, timeScale })`: the last `window` s of `signal(τ)` (τ is the signal's own seconds, `t × timeScale`, so a slowed film still shows the real waveform) with its time base; `{ points, values, perDiv }`. `meter(ctx, { value, units, label, digits, x, y, size })`: `{ text }`. `gauge(ctx, { value, min, max, units, label, sweep, x, y, r })`: a needle linear in the value, held at the ends; `{ angle, clamped, frac }`. `bar(ctx, { value, max, units, label, x, y, w, h })`: `{ fill, text }`. |
| `fields.js` | Invisible fields drawn by their law in SI units, every `at(t)` a pure function of t. Sources (positions in scene units or `(t) => Vector3` for a moving source; a non-finite or zero strength is refused): `charge(q, at)` (coulombs), `dipole(p, at, { d })` (moment in C·m as two charges ±|p|/d, default d 1 mm), `straightWire(I, a, b)` (closed-form Biot–Savart, right-hand rule), `loop(I, { at, normal, R, segments })` (counter-clockwise seen from the tip of `normal`, 128 pieces), `barMagnet({ at, axis, length, width, depth, Br, grid })` (a uniformly magnetised block as two sheets of magnetic charge; `Br` in tesla has NO default, it comes from the film's model with a source: sintered NdFeB ~1.3 T, alnico ~1.2 T, ferrite ~0.4 T; exact outside the block, a line entering the box ends as a `sink`; `mesh` at real size with `userData.real`, `place(t)`). `field(sources)` → `{ kind, at(p, t, out) }` in V/m or T by superposition (mixing E and B sources is refused, `/kind/`). `trace(F, seed, { t, dir, step, maxLength, stop, sinkRadius })`: RK4 along the unit field direction, step 5 % of the distance to the nearest source, in METRES, ending `sink`, `stop`, `closed`, `length` or `singular`. `seeds(F, { count, seedRadius })` and `fieldLines(F, { count, seeds, mode, width, arrowEvery, maxLength, color })`: the `count` lines are shared among the sources by flux and spaced to carry equal flux (a Fibonacci sphere round a charge, equal area on the N face, equal flux across a loop's disc, equal steps in ln r round a wire), so in the 3D set line density IS strength; a hand-picked or planar set (`seeds`) shows direction only, not strength. Tubes with arrowheads along F; `mode: "teach"` draws them on top of the world (`depthTest` off, `renderOrder` 10), `"world"` depth tests them (a field has no light in it: its in-world form is filings and compasses); `reveal(u)` grows every line from its start on cue and `at(t)` traces again when a source moves. Returns `{ group, lines, tubes, arrows, seeds, reveal, at }`. `filings(F, { at, w, d, count, seed })`: an `InstancedMesh` of real-size filings (4 mm × 0.3 mm) on a sheet (normal +Y), each along the field's in-sheet component (random where there is none), `{ mesh, points, dirs, at(t) }`. `compass(F, { at, r, I, m, damping, t0, angle0 })`: a needle turning by the field's torque on its moment with inertia and damping, integrated at a fixed 1/2400 s into a cache so `at(t)` → `{ angle }` is pure of t (defaults from the needle's size: an assumption, override with the film's own). |
| `optics.js` | Light as a subject: rays traced through the set's surfaces by Snell's law and the Fresnel split (unpolarised, 1 past the critical angle), with the index of a CITED material (`MATERIALS`: `air` Ciddor 1996, `water` a Cauchy fit to Hale and Querry 1973 at 20 °C, `bk7` Schott Sellmeier, `fusedSilica` Malitson 1965; `material({ n, source })` or `{ sellmeier, source }` for another, refused without a `source`, `/source/`) and a few wavelengths for dispersion (`WAVELENGTHS` 450, 550, 650 nm, `wavelengthColor`). Elements, positions in scene units, sizes in metres: `interface({ at, normal, below, above, size })` (an infinite flat boundary, a water surface), `lens({ at, axis, R1, R2, thickness, diameter, material })` (two spherical caps and a rim, R signed as in the lensmaker's formula, ±Infinity a flat face; a bad radius is refused `/R1/`, a rim wider than its sphere `/diameter/`, faces that cross at the rim `/faces cross/`; `focal(λ)` thick-lens f, `bfd(λ)` back focal distance, `thin(λ)` the thin-lens f), `mirror({ at, normal, R, diameter, reflect })` (plane or spherical; the back does not reflect), `prism({ at, apex, height, length, material })`, and `surfaceFromMesh(mesh, { inside, outside })` for any CLOSED, outward-wound mesh of the set, refracting by its own normals through the mesh's transform. `traceRay(elements, { origin, dir, λ, power, maxDepth, minPower, escape })` in METRES returns `{ segments, rays, power, length }` (a Fresnel split at every surface, total internal reflection, branches under `minPower`, a share of the source `power`, dropped; elements must not overlap). `bundle(elements, { source: { at, dir, kind: "parallel" \| "point", radius \| halfAngle, count }, wavelengths })` traces a real beam (a torch, the Sun) at each wavelength; `image(λ)` is where the main rays converge, `{ point, pointM, spread, focal }`, the focal length and image point in metres for the film's model to put in `numbers.json` and the narration to say. `apparent(point, eye, surface)` is where a submerged point is seen through a flat surface (the sight line bent by Snell's law, the textbook apparent depth; a point a rounding error above the surface counts as on it). `drawRays(result, { mode, width, arrowEvery, dust })`: `"teach"` clean tubes (thinner for weaker branches) and arrowheads on top of the world, coloured by wavelength; `"world"` light shafts in dust, additive and depth tested, which need `dust` (the scattered fraction, `/dust/`: no dust, no visible shaft); `reveal(u)` grows every ray from its source. `caustic(bundle, { surface, base })` is the bright disc where the beam lands on a plane, sized by where the rays arrive and as bright as the light is concentrated (clamped to 1; the source `power` is a unit, never a brightness). Lens, mirror, prism and interface give a `mesh` at real size. |
| `air.js` | `jet({ frame, D, u0 })`: air blown from any outlet (a fan, a blower, a vent, an exhaust) as a turbulent round jet; `frame(t, outlet, axis)` moves or turns it; `wind(p, t, out)` — the air velocity at p, for what the air carries; `block(objects)` makes obstacles shadow it. |
| `grains.js` | `grains(k, { preset, at, radius \| width, depth, bottom, height, layers, jitter, cut, instances })`: a bulk of small things (presets `lentil`, `coffee`, `rice`, `oats`, `sugar`, `sand`, `gravel`, or your own `l`, `t`, `w`, `shape`, `colors`) as instanced grains at real size in jittered layers on the top and, with `cut` (the cutaway's `{ normal, offset }`, world space, any plane), whole grains at the cut face that follow the cutaway's `on`/`off`/`set` and a rotated container (the cutaway calls the fill's `userData.cutTo`; without one call `result.cutTo(plane)`), over a body wearing the matching `grains` surface; `instances: false` for grains under ~3 px (the body's texture alone). Static dressing, never a pour. Returns `{ group, body, mesh, counts, capped, cutTo }`. |
| `finish.js` | `makeFinisher(canvas, { grain, edge, fps })`: `layer(gl, i)` for motion-blur sub-frames, `grade(t)` vignette and seeded grain. |
| `studio.js` | `studio(renderer, scene, camera, { look, preset, route, set, env, tone, ao, shadow, dof, finish, mpu, height, stencil })` -> `{ composer, render(t, pose), frame(t, pose), state(pose), camera, key, lights }`: the one light and render rig, never hand-written. Looks `diorama` (Neutral tone mapping, RoomEnvironment 0.9, AO) and `toon` (no tone mapping, no AO); presets `warm`, `window`, `overcast` (key, fill, rim around the set). The key's shadow frustum is refitted every frame to what the pose sees (`fitShadow`: the part of the set inside the frame's pyramid, the ground and props far behind the target too, since a fragment outside the shadow camera is lit; texel <= 1 mm while the frame sees under about 4 m of the set, never coarser than one frustum over the whole set; the depth range keeps every caster of the set, so `set` must cover a part's whole travel); `render`/`frame` place the camera at the pose, and the frame is that camera's (the composer is bound to it); N8AO radius = the view's half-size / 12 in metres, clamped 4 mm..0.5 m (`aoFor`, from the scale, never typed); DOF focus on the pose's target, its `focusRange` in metres (default 3; the effect reads world units, so it is divided by the scale); SMAA, then `finish`. | `markings.js` | `markings(target, items, { wear, seed })`: printed text, symbols and stickers on any mesh at real size, built by casting a grid of points onto the surface along the print's normal and lifting each hit by the print's thickness, so it follows a cylinder and is never flattened by the target's (non-uniform) scale; a child of `target`, so it moves with it. Item `{ text (string or lines) and / or icon ("W012" ISO 7010 electricity, "earth", "class2", "dot", "vent", "screw"), h (cap height, metres), at (the print's centre on the surface, a Vector3), normal (outward), style, up, wear, size, w, hh, ink }`; `style` is `pad`, `silkscreen` (capitals), `laser` (the target's colour, paler) or `sticker` (paper, one corner curled, never above 1.5 mm). ## The shape of a set's build

1. `makeKit` with the measured `mpu` and the floor's height; place models and props, `rest()` what is set down.
2. `settle()` once everything is placed; read what it could not place. Declare the real size of each hero prop (`userData.real = { h: 0.18 }`) and read `scaleAudit(scene)`: a 10x typo is named here, not by a reviewer; `zFight(scene, { cameras })` with every station's camera before the first render.
3. Pose every moving part as a pure function of t from its cause: a driven wheel from its driver by the tooth ratio
   (`transmission.js`), a part that drops by the place's gravity (`G` from `makeKit`) with an eased landing and a
   contact squash of a few percent, a latch on its cue from `BEATS`. Nothing integrates step by step, so a seek to any
   frame gives the same pose.
4. Render loop (light and render with `studio()`, not a hand-written rig): pose everything at `t` (a slowed shot at `tau(t)`); when `travel(t, fps)` passes ~4 px of a frame, average 5 sub-frames across a
   180° shutter through `finish.layer`, then `finish.grade(t)`.

### A transmission

A 12-tooth pinion driving a 36-tooth gear, and a chain whose links move with the cranks. The ratio decides the second
wheel's angle; the shapes are real size; nothing turns the second wheel by hand.

```js
import { involute, meshing, gearGeometry, loopPath, linkPoses } from "./transmission.js";
const g1 = involute({ module: 0.002, teeth: 12, pressure: 25 }), g2 = involute({ module: 0.002, teeth: 36, pressure: 25 });
const { centre, phase2 } = meshing(g1, g2);              // centre 48 mm; refuses a pair that interferes
pinion.geometry = gearGeometry(g1, { width: 0.01 });     // metres: scale the mesh by 1/M
const drive = (t) => 2 * Math.PI * 0.5 * t;              // the driver at 0.5 turn/s, from the cause the film names
pinion.rotation.z = drive(t);
wheel.rotation.z = phase2 - drive(t) * 12 / 36;          // 1/3 the speed, the other way
// a chain: links on the loop, at the distance the driver has moved (ω·r)
const path = loopPath([{ x: 0, y: 0, r: R1 }, { x: C, y: 0, r: R2 }]);       // C from centreFor({ links, pitch, r1: R1, r2: R2 })
const poses = linkPoses(path, { pitch, phase: (drive(t) * R1) % pitch });
```
