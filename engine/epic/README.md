# engine/epic — the design languages

Vendored from [OrRon/EpicInfographics](https://github.com/OrRon/EpicInfographics) @ bf97e58
(`skills/epic-infographics/references/`, MIT, `LICENSE`), cut to what DALANG uses: three of its design languages and
two of its references, each trimmed to the parts a step reads (palette, type, geometry, data styling, signature
devices, do/don't; patterns and tension rules; chart rules). Its other languages, references, scripts, skeleton and
CSS keyframes are not kept: HyperFrames renders and motion is a pure function of t (`engine/iso`, `engine/three`).
Which language a beat uses, and what a look outside the Brief's two gets: `references/looks.md`.

| File | Read |
|---|---|
| `languages/<one>.md` | each language the film uses (`isometric-world`, `cutaway`, `blueprint`) |
| `composition.md` | when a beat's last frame picks its named pattern (`references/express.md`) |
| `charts.md` | before drawing any chart |

Every language runs wide (1920×1080) and story (1080×1920); its type scale is for a 1080 px short side.
